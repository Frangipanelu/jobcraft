# Session: 2026-08-03

## 概要
本轮目标：对前端执行 hallmark audit，将「极简编辑」设计系统落地为可执行规范，并修复 audit 发现的所有问题（2 critical · 5 major · 5 minor）。

## 背景
- 上一轮（v0.9）已建立 `--jc-*` 设计 token 与风格，但 audit 发现 token 未被实际消费：6 个页面仍大量内联裸色值、小屏横向溢出、emoji 当图标、卡片套卡片、span 假装按钮等。
- 本轮为纯前端 UI 层改动，后端零改动。

## 架构决策
- **Token 纪律升级为红线**：组件内禁写裸色值（PDF 离屏容器 `#ffffff` 因保 A4 白底豁免），设计事实以 `docs/UI_DESIGN.md` 为准。
- 状态色（success/warn/danger）走语义 token；AntD Tag 预置色（`green`/`orange`）仍可作轻量标签，但大块背景/文字必须走 token。
- 响应式下限为 320px 无横向滚动 + 点击文本不折两行。
