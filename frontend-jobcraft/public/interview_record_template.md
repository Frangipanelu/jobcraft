# 面试复盘记录模板

## 一、基本信息（可选）

- 岗位：高级后端工程师
- 公司：测试公司
- 轮次：技术面 / 业务面 / HR面
- 时间：2026-07-10

## 二、面试对话（必填）

请按下面格式填写，每轮对话以 `面试官：` 或 `我：` 开头，时间戳可选。

```text
面试官 09:00 请你先做一个自我介绍。
我：我叫李明，毕业于某某大学计算机专业，之前在一家电商公司做了3年后端开发。

面试官 09:02 你们订单系统每天的量级大概是多少？
我：日均几百万单。

面试官 09:05 遇到过什么性能问题？
我：大促时数据库压力大，我们做了缓存和分库分表。
缓存主要抗读流量，分库分表按用户ID取模。
```

## 三、支持的说话人标签

以下标签都会被自动识别，建议固定使用一组：

- 面试官：`面试官`、`Interviewer`、`Q`、`问`
- 面试者：`我`、`候选人`、`面试者`、`Candidate`、`A`、`答`

也支持中性代称，系统会自动推断身份：

- `A / B`
- `Speaker 1 / Speaker 2`
- `甲 / 乙`
- `男 / 女`

## 四、语音转文字“讲话人+时间戳”格式

如果你的转写工具输出的是 `讲话人1 - 0:00` 这种格式，直接粘贴即可，系统会自动识别说话人并基于内容推断身份：

```text
讲话人1 - 0:22
那麻烦您做一个简单的自我介绍。

讲话人2 - 0:26
我叫李明，毕业于某某大学计算机专业。
```

支持的代称：`讲话人1/2`、`Speaker 1/2`、`发言者1/2`、`A/B`、`甲/乙` 等。

## 五、仅时间戳格式

如果语音转文字只带了时间、没有说话人，也可以直接上传，系统会按轮次交替推断：

```text
09:00 请你先做一个自我介绍。
09:01 我叫李明，毕业于某某大学计算机专业。
09:02 你们订单系统每天的量级大概是多少？
09:03 日均几百万单。
```

## 六、注意事项

1. 每一轮问答建议保留完整的 `面试官：...` + `我：...` 成对出现。
2. 如果一句话被语音转文字分成多段，只要第一段带 `我：` 标签，后续无标签行会自动合并到同一条回答。
3. 无标签行跟在面试官问题后会被推断为面试者回答；跟在面试者回答后会被合并为续行。
4. 上传前可以点击页面上的「解析预览」，先确认说话人拆分是否正确，再调用 LLM 分析。
5. 如使用 PDF / DOCX / MD / TXT 上传，文件中保留上面的纯文本格式即可，Markdown 标题和说明文字不影响解析。
